What is this?

A non-partisan way to find which candidate in California's June 2026 governor primary you actually line up with — and exactly why. A few things set it apart from the usual candidate quiz:

  • Only questions where the candidates actually differ. No "do you support good schools?" filler — every question is one the field is genuinely split on, chosen by spread.
  • You can keep asking. From any question, hand the topic to ChatGPT or Claude — pre-loaded with that topic's sourced guide — and go as deep as you want. It also works in agentic browsers like Dia, or copy the prompt into any AI agent you like.
  • An AI-researched, fully-cited dataset. Every candidate position was researched and assembled by AI from primary sources — not hand-curated by a research team — and each one links to a dated quote you can open and check yourself.

How this works

  • 20 questions in all — skip any you'd rather not answer.
  • Per-question importance slider; defaults to medium so you can just answer.
  • Two separate scores per candidate: policy match and personal fit.
  • Every position links to a primary-source quote. Flag anything that's wrong.

We log anonymized response counts to build a public stats page. No tracking cookies, no IPs stored.

Questions & methodology

How were the questions chosen?

Every question is one where the candidates actually differ. We start from the full matrix of candidate positions and rank each issue by a differentiation score — how widely the field spreads, scaled by how well-researched the issue is. The questions you see are the highest-spread issues. Topics where nearly everyone agrees become footnotes, not questions. (The full ranking, including the lower-spread issues, is in the open dataset.)

How were the candidate positions researched?

The dataset was researched and assembled by AI, working from primary sources — there was no human research team hand-curating it. The guardrail that keeps it honest: every position links to a primary source — a campaign website, interview, debate transcript, op-ed, or voting record — with a verbatim quote, a link, and a date, and any issue a candidate hasn't publicly addressed is marked "unknown" rather than guessed (10 of 200 positions are honest unknowns). So you never have to take the AI's word for it — open the source on any position and check it yourself. Expand "Background & arguments" on any question to see the sourcing.

What if I think a position is wrong?

On your results page, expand "see why you matched" under any candidate — each cited position has a ⚑ flag this button. You can also open an issue or pull request on GitHub. Both routes feed the same correction queue, and the entire dataset is public so anyone can audit it.

How is my match calculated?

Simple, auditable math — no black-box AI ranking. For each question we compare your stance to each candidate's on the same scale, weight it by how important you said the issue is, and average. You get two separate scores — policy match and personal fit — that are never blended into a single number. Candidates with an "unknown" position on a question are simply not scored on it.

Is this partisan?

No — it's a non-partisan, open-source project, not an endorsement engine. Every stance scale is written so neither end is "the right answer," and each question shows steelmanned arguments for both sides. The goal is to help you find alignment, not to tell you who to vote for. Code and data live on GitHub.

Can I dig deeper on a topic?

Yes — this is the part I'm most excited about. On every question, under "Go deeper," type a question and hand the topic to ChatGPT or Claude in one click — it opens pre-loaded with that topic's sourced guide so the AI can reason from the same primary sources. It also works in agentic browsers like Dia that can read the page directly, and there's a Copy prompt button so you can paste it into any AI agent you prefer. Power users can also connect the project's MCP server to Claude or Cursor — see the GitHub repo.

Is my data tracked?

We log anonymized aggregate counts (which answers get chosen, which candidate matched) to build a public stats page. No cookies, no IP addresses, no per-person profiles. Your individual answers stay in your browser, and your shareable result link encodes your answers in the URL — not on our server.

How current is this, and can I use it in my own AI assistant?

Every page shows a snapshot date; positions can shift during a campaign, so we version the dataset and re-check as the June 2026 primary approaches. There's also an MCP server that plugs the dataset into Claude or Cursor, so you can talk through the issues conversationally — see the GitHub repo for setup.
